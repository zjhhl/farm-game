# 3D 模型素材目录

把下载的 **GLB 格式** 模型放到这个目录，按下面的文件名命名，游戏会自动加载并替换对应的程序化几何体：

| 文件名 | 用途 |
|--------|------|
| `tree.glb` | 树（共 6 棵） |
| `scarecrow.glb` | 稻草人 |
| `fence.glb` | 木栅栏 |
| `windmill.glb` | 风车 |

## 注意事项

- 必须是 `.glb` 格式（GLTF 二进制，Three.js 直接支持）
- 模型太大 / 太小 / 位置不对 → 在 `js/render3d.js` 顶部的 `MODEL_SPECS` 里调整对应的 `scale`
- 想回退到程序化画面，删掉对应 `.glb` 文件即可
- 模型建议选「低多边形（low-poly）」风格，视觉更统一
